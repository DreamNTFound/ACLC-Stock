# ACLCStock – School Merchandise Monitoring System

A web-based application designed for ACLC College of Tacloban that helps students and staff monitor the availability of school merchandise like ID laces, PE uniforms, and more. The app provides real-time stock updates, reservation features, and easy management for admins.

---

## 🎯 Purpose

The purpose of ACLCStock is to streamline the monitoring and management of school merchandise stock, providing students with timely updates on availability and allowing administrators to efficiently manage inventory, reservations, and restocking schedules. This system aims to improve accessibility, reduce manual stock checking, and enhance overall convenience for both students and staff.

---

## ✨ Features

- Real-time stock availability for school merchandise  
- Secure student login using University/School Number (USN)  
- Admin dashboard to manage stock, reservations, and restock schedules  
- Merchandise details and reservation system for students  
- Responsive and intuitive user interface accessible on multiple devices  
- Role-based authentication to ensure data privacy and security
